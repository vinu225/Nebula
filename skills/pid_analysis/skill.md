# Skill: P&ID and Engineering Drawing Analysis

## ISA-5.1 Instrumentation Standards & Flow Review
1. Identify primary lines, bypass lines, drains, and vents.
2. Extract instrument identification tags:
   - First letter: Measured variable (e.g., P = Pressure, T = Temperature, F = Flow, L = Level).
   - Second letter: Function (e.g., I = Indicating, C = Controlling, T = Transmitting, V = Valve).
3. Identify safety-critical items:
   - PSV (Pressure Safety Valves) / PRV (Pressure Relief Valves)
   - ESDV (Emergency Shutdown Valves)
   - Rupture discs and interlocks.
4. Highlight inconsistencies such as missing isolation valves or uninstrumented headers.
