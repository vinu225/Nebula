# Skill: Approval Note Generation

## Formatting Guidelines for Public Sector Enterprises
Structure all generated approval notes with the following obligatory sections:
1. **Header**: Confidential / Internal / File No. / Date / Dept.
2. **Subject**: Concise and capitalized statement of action sought.
3. **Background**: Contextual facts, previous approvals, reference letters.
4. **Proposal & Justification**: Technical and operational rationale for proposed action.
5. **Financial Implications**: Estimated cost, budget head, tax applicability (GST).
6. **Competent Authority Recommendation**: Clear recommendation citing the delegation of powers (DOP).
7. Generate the final output as a professionally formatted `.docx` file ready for download.
