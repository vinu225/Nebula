# Skill: Inspection Report Analysis

## Domain Guidance (Refinery & Petrochemical Operations)
1. Read ultrasonic thickness measurement (UTM), magnetic particle testing (MPT), dye penetrant (DPT), and visual inspection records.
2. Cross-reference measured wall thickness against minimum retirement thickness (MRT) according to API 510 / API 570 codes.
3. Check for corrosion rates, pit depths, weld joint defects, and blister formations.
4. If an anomaly exceeds permissible thresholds:
   - Flag criticality: HIGH (immediate shutdown/repair), MEDIUM (scheduled turnaround), LOW (monitor).
   - Draft an official Approval Note recommending corrective maintenance or derating.
