# Skill: Industrial Document Analysis

## Instructions
1. Parse attached documents using the PDF parser or OCR tools if pages are scanned.
2. Maintain strict factuality: cite section numbers, tables, and page references for every claim.
3. Identify discrepancies, ambiguities, or compliance risks with respect to industrial standards.
4. Provide structured outputs including:
   - Executive Summary
   - Key Technical Parameters
   - Observations & Deviations
   - Actionable Next Steps
