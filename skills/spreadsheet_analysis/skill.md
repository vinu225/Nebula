# Skill: Refinery Spreadsheet and Tabular Data Analysis

## Processing Instructions
1. Load CSV/Excel sheets into Python data structures (Pandas DataFrames in sandbox).
2. Validate columns, headers, units of measurement (e.g. BPD, Barrels per Day, MT, Deg C, Bar).
3. Compute variances between scheduled vs actual production metrics.
4. Output clean summaries and, where requested, generate formatted `.xlsx` workbooks with formulas and highlighted anomalies.
